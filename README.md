# TARO GAME 🐾

おなじ大きさの子どうしがくっついて、ひとつ大きな子になる、まんまる ころころゲームです。

**あそぶ** → https://ユーザー名.github.io/taro-game/
（GitHub Pages を有効にしたあと、このリンクを自分の URL に書きかえてください）

## スマホやパソコンに「アプリ」として入れる

ページを開いてから、

- **Android の Chrome** … 右上の「⋮」→ **アプリをインストール**（または「ホーム画面に追加」）
- **iPhone の Safari** … 下の共有ボタン → **ホーム画面に追加**
- **パソコンの Chrome / Edge** … アドレスバーの右はしに出る **インストール**（⊞）のマーク

入れると、アドレスバーのない全画面で開き、アイコンは犬ボールになります。一度開いていれば、電波がなくても遊べます。

## あそびかた

- カーソル・指でなぞって横に動かし、はなす（タップ・クリック）と落ちます
- キーボードは ← → で移動、↓ かスペースで落とす
- おなじ大きさの子どうしがくっつくと、ひとつ大きな子になります
- 赤い線より上に積みあがるとゲームオーバー

### ふたつのモード

| モード | ないよう |
|---|---|
| **3分バトル** | 3分間で点数を競います。むずかしさはみんな同じ。名前ごとに記録が残り、1位〜3位に王冠がつきます |
| **∞（エンドレス）** | 時間なし。いちばん大きい子ができたら終わり。やさしい／ふつう／むずかしい が選べます |

### 点数

| | 倍率 |
|---|---|
| リボンの色がそろう | 2倍 |
| 虹色の子が同じ大きさの子と合体 | 3倍 |
| 虹色どうしの合体 | 5倍 |
| クリア（いちばん大きい子ができる） | 7倍 |

### 空のようす

昼は太陽と小鳥、夕方は夕日とカラス、夜は月と星とフクロウ。赤い線にとまったり、飛んでいったりします。
ときどき空をとぶ人や UFO も来ます。UFO は子をひとりさらっていくか、**虹色の子**を置いていきます。
∞ モードの空は、いま実際の時刻に合わせて変わります（月の満ち欠けも本物です）。

## ファイル

| | |
|---|---|
| `index.html` | ゲーム本体。これひとつでも遊べます |
| `manifest.webmanifest` | アプリとして入れるための設定 |
| `sw.js` | 電波がなくても開けるようにするしくみ |

記録と設定は、その端末のブラウザに保存されます（サーバーには何も送りません）。
